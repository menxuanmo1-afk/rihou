# iPhone 助理验收清单

当前不发布 App Store。Worker 已部署，2026-09-19 两次虚构记录真实 DeepSeek 连通测试均成功；这不替代真机验收或内容质量评估。`npm run ios:sync` 后用 Xcode 将新构建装到测试手机。已有日记需先导出备份。

1. 无数据时，助理显示补记睡眠的空态；未配置 Worker 时明确显示 AI 尚未连接，没有假的亮点/问题。
2. 连续记两次起床：昨日统计从上次起床开始；23:00–07:00 睡眠显示 8.0h，通勤不算消费；休息和消费不混淆。
3. AI 已配置并授权时，刚补记睡眠仅生成一次；切页/重开不会重复。修改昨日块后可更新；模型失败保留日记，可手动重试。周日上午不出周报，周日14:00后出现。
4. 亮点/问题贴在实际时间线旁，深度分析展开才显示机制、影响、方法和边界。不出现知识库、消息列表、“为什么选这个”或“安排依据”。
5. 计划/待办复盘默认两句；今日建议可含多条作息改进、今日到期及逾期待办。采纳待办后仅加入未来无冲突空档，时长半小时，待办不自动完成。
6. 顶部为“设置 / 记到现在”。设置支持自定义事项、计划/作息通知、锁屏隐藏标题、AI 连接和备份。
7. 通知允许后，建一个 12 分钟后开始的计划，约 2 分钟后应收到提醒。拖动到别的时间，原提醒取消；删计划同样取消；不允许通知时记录和计划照常可用。
8. 锁屏隐藏标题默认开启；详细模式开启后显示时间和名称。测试 App 前台、后台、进程结束、跨午夜、循环计划、系统时区改变与专注模式；以实际 iOS 行为为准。
9. 启用饭后散步后，将吃饭刚刚结束的记录保存，收到情境提示；“开始”有空档才建10分钟计划，“5分钟后”最多一次，“今天不提醒”只停该规则。旧记录编辑、昨天补录不应触发饭后推送。
10. 导入备份不会自动同意上传给 AI，需重新授权；访问码不包含在备份内。App 包内无 DeepSeek 密钥、知识全文、旧估值计算和旧分析导出模块。
11. 网页仍有资产图、估值栏、自定义估值与原 AI 导出。不要把原生助理 CSS 加到网页入口。

已执行的自动化覆盖见 `tests/assistant.test.mjs`、`tests/coach-worker.test.mjs`；原来的三组时间线/待办测试继续运行。Xcode 编译与浏览器模拟不能代替上述真机通知与真实服务验收。
